# Evaluating GDPR and EU AI Act Safeguards Against AI-Driven Data Exposure

This repository contains the simulation code and replication materials for the paper: **Evaluating GDPR and EU AI Act Safeguards Against AI-Driven Data Exposure in National Security AI Systems**.

## Overview
This project empirically evaluates whether superficial, nominally compliant technical safeguards inspired by the GDPR (Generalization) and the EU AI Act (Naive Input Perturbation) effectively mitigate data exposure risks (specifically, Membership Inference Attacks) in government risk-scoring AI systems.
